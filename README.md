## What Apexlog Does

Apexlog gives motorsport fans and sim racers a straightforward way to examine relationships between vehicles and circuits. It connects tracks with recommended cars while also providing references for different racing series and scenarios.

Everything is presented through a focused browser interface. Search for circuits, investigate compatible pairings, and narrow vehicle results by category or manufacturer. The application also includes light and dark themes and is designed to remain available offline once installed.

## Frequently Asked Questions

### Is Apexlog itself a simulator?

No. It is a reference tool for exploring car and circuit combinations, not a replacement for a racing simulator or game.

### Can the guide look up one particular circuit?

Yes. Search by track name to find the circuit and view its available vehicle suggestions and pairings.

### Are vehicle results filterable?

Yes. You can refine the results using vehicle category and manufacturer.

### Can it be used without internet access?

Yes. After installation, the application is designed for offline use as long as the necessary project files are still stored locally.

### Where is the theme changed?

Use the interface theme control to select either light mode or dark mode.

### What if Apexlog fails to open?

Make sure extraction completed successfully, preserve the project directory structure, and open the main HTML file in a current browser. If the problem remains, download the latest build and test it separately.

### Where do updates appear?

New versions are provided through the project repository and its download page. When an update is published, download the latest build again.
